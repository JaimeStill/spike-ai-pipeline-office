# spike-ai-pipeline-office

The Open XML CLI of spike-ai-pipeline, released by tag and run by spike-ai-pipeline-processing as
a system tool. This context records only working knowledge the code and the README do not
express; the spike's question and evidence live in the root repository's `context/README.md`.

## Capability map

- **extract**: docx, xlsx, and pptx to the JSON document model, through the Open XML SDK.
- **render**: the same model as Markdown.
- **media**: embedded pictures and chart series written out beside the model.
- **release**: NativeAOT binaries for linux-x64 and linux-arm64.
